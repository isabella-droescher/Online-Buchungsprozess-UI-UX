# Online-Terminbuchung beim Friseur (UI/UX Design)

## Projektbeschreibung
Ein Friseursalon möchte seinen Kund*innen ermöglichen, Termine einfach online über seine Website zu buchen. 
Dafür wurde ein moderner, benutzerfreundlicher Buchungsprozess mit 3–5 Schritten entworfen. 

## Ziel
Entwicklung eines klickbaren Desktop-Prototyps mit 3–5 zusammenhängenden Screens, der den gesamten Buchungsprozess abbildet.

## Design
- Modernes und minimalistisches Design
- Übersichtliche Benutzerführung
- Intuitive Bedienung
- Harmonische Farben und Typografie
- Klare Fortschrittsanzeige

## Format
- Desktop-Website
- UI/UX Design
- 3–5 Screens
- Klickbarer, interaktiver Prototyp

## Ergebnis
Ein intuitiver Online-Buchungsprozess, der Kund*innen eine schnelle und unkomplizierte Terminvereinbarung ermöglicht.
